# 玄枢 · 谱规范 v1

> 状态：v1（定义稿）｜日期：2026-10-11
> 适用范围：玄枢「谱」的数据格式与创建/加载规则（待定项 #9 的格式部分；画面/编辑 UI 留 UI 阶段）
> 术语：见 `CONTEXT.md`。谱 = 信息型系统，不干活（ADR-0005）；藏不是谱（ADR-0003）；工作区/工作流不是谱。

---

## 1. 物理形态

- **默认 = 一个目录**；**最小单位 = 一个文件**（单文件自身即谱，视为「无 summary 的简谱」）。
- 目录结构：

```
pus/<谱名>/
├── manifest.md        # 元数据 + 概览（人 + AI 都先读它）
├── <内容文件>.md      # 正文，自由分节（一级标题 = 固定字段结构）
└── summary.md         # 精简汇总（AI 优先读；可无）
```

- 谱名 = 目录名（slug 化：小写、`-` 连接、可含中文）；谱名唯一。

## 2. manifest.md（YAML frontmatter）

```yaml
---
spec: pu/1              # 谱规范版本（预留演进）
name: 软件开发           # 显示名
level: optional         # base | optional（级别≠必填）
tags: [工作, 技能]       # 签：预留字段，功能暂不启用
source: manual          # manual | ai-assisted | sediment（沉淀）| workflow
updated_at: 2026-10-11  # 人/AI 最后更新
---
# 软件开发（概览）
（一段话说明这个谱是什么、覆盖哪些内容；AI 优先读这里）
```

- 正文 = frontmatter 之后的内容，**一级标题分节**即「固定字段结构」——各谱分节自定（规范有弹性，不写死字段表），但必须含「概览」节。
- `level: base` 参与底稿提炼；`optional` 默认不参与、问事时追加（级别只影响取用，不影响必填——只有底座八字必填）。

## 3. summary.md（汇总文档）

- 一份**精简汇总**：覆盖该谱的关键事实与结论，供 AI 快速定位、节省上下文；AI 优先读 summary，需要细节再读内容文件。
- **生成**：创建/更新谱时由 AI 提炼（内置 skill），**更新权在人**——AI 的提炼可能偏差，人可改（与底稿「纯派生不可改」相反，谱的 summary 人可编辑）。
- 缺失时不阻塞：AI 退读 manifest 概览 + 内容文件。

## 4. 级别语义

| 级别 | 含义 | 参与方式 |
|---|---|---|
| `base`（基础输入级） | 优先级高、关于「你」的既定事实（人生经历等） | 进底稿提炼源；问事默认候选勾选 |
| `optional`（可选输入级） | 某侧面（工作、3D 打印、软件开发…） | 底稿不采；问事时按需追加 |

级别 ≠ 必填：所有谱都非必填（底座八字是唯一必填项，属底座、非可选谱）。

## 5. 创建流程（AI 辅助，人确认）

1. 点「创建新谱」→ 输入：打字 / 附件（MD/PDF/任意文件；语音后置 v2）
2. 定义谱名
3. AI（内置 `xuanshu:create-pu` skill，借用 DSH coding 工具）把资料转成 manifest + 分节正文 + summary
4. 生成后展示（名称 + 描述 + 细节）供确认
5. 确认后落盘 `pus/<谱名>/` → 谱列表出现新谱

## 6. 加载协议（AI 取用）

- 问事勾选谱 = 把谱路径写入会话 meta → 注入上下文时：**manifest 概览 + summary 优先** → 按需读内容文件（由 AI 自己决定深入哪些分节）。
- 底座（八字）**默认加载、始终在场、不可关**；底稿（`digao.md`）**默认必加载**（它本身是与八字同级的基础谱）。
- 谱日常不参与执行；只在「创建谱」时借用 coding 工具（ADR-0005）。

## 7. 更新权规则

- **人为主**：手工编辑谱（任何编辑器均可，格式为人可读的 MD）。
- **沉淀写回必须人工确认**：问事「导出汇总」→ AI 生成草稿 → 人点「更新到谱」才写入；AI 不静默、不自动写（铁律 2）。
- **例外**：工作区/工作流的自动扫描沉淀只进底稿、不生成谱条目（谱与工作区/工作流不可互相转换）。

## 8. 边界重申（防误用）

- 谱**不是**插件/能力：不给谱加执行逻辑、工具、沙箱（ADR-0005）。
- 谱**不是**藏：谱进 AI 上下文；藏永不进（ADR-0003）。
- 谱**不是**工作区/工作流：三者并列、不可互相转换；谱不出现在工作区列表，反之亦然。
