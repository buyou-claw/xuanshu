# 玄枢品牌标说明（brand-mark-notes）

> 台账：asset.S15-2 ｜ 类型：icon（玄枢品牌标 `sidebar.brand.mark` + 品牌名排版位 `sidebar.brand.name`）｜ 屏：S15《管理入口与骨架落位》§2A①、§4 `XsBrandMark` / `XsBrandName`
> 文件：`brand/brand-mark.svg`（单色 currentColor 版）、`brand/brand-mark-color.svg`（品牌色版）。

## 构图

一枚简洁几何标，取「**枢轴 / 璇玑**」意象——**圆环绕一偏心枢点**：

- **圆环**：绕行的圈——「玄」的底座，深稳、合围、始终在场；也是璇玑的环。
- **偏心枢点**（实心圆点，偏在环心下方）：「枢」——门轴 / 中枢，万物绕之转动的那一点；偏心而非居中，取璇玑「环有轴而轴不正中」的仪器感，也让标在小尺寸下有一个明确的视觉锚。
- **过心辐条**（自枢点上方竖直上行、穿环心、指环顶）：转动的半径 / 指针——「枢主运转」，一条把「底座（环）」与「中枢（点）」连起来的轴意。

三笔成标（环 + 辐 + 点），无衬线、无渐变、无文字；向「门轴」意象可读（竖辐 = 门轴，环 = 绕轴之转），向「璇玑」意象也可读（环 + 枢 + 指）。

## 两个版本

| 版本 | 文件 | 用色 | 用在哪 |
|---|---|---|---|
| 单色 currentColor 版 | `brand/brand-mark.svg` | 全部笔画 `currentColor`，随宿主文字色继承 | 默认版本；侧栏品牌位、面板头、任何需要随主题变色的场景 |
| 品牌色版 | `brand/brand-mark-color.svg` | 玄青 `#2f3a5c`（light，README §5 登记） | 需要品牌识别色的场景（首启 hero、关于位等）；**dark 模式实现切换 `#a3b0e0`**（§5 已登记；静态 SVG 只承载 light 值，切换由实现票按主题完成） |

## 多档边长下的简化规则

`viewBox` 统一 24，不写固定宽高；尺寸由消费方给：

| 档位 | 边长语义 | 呈现规则 |
|---|---|---|
| 品牌主图形档 | `--xs-size-glyph-brand`（品牌主图形边长；S1 页头 / `conversation.hero.brand.mark` 若用） | 完整三笔（环 + 辐 + 点） |
| 侧栏品牌档 | `sidebar.brand.mark` 宿主尺寸（随 DSH 侧栏行高；与 `--xs-size-icon-sidebar` 同量级） | 同一 SVG 缩放即可，三笔在 16–20 档仍可读 |
| 极小档（≤12，如 favicon 位 / 行内缀标） | 无对应 token（不在 v1 界面清单） | **简化规则：去辐条，只留环 + 偏心枢点**——两笔仍保有「环 + 枢」识别；需要时由实现票从 `brand-mark.svg` 删辐条派生，不另存第三份文件 |

笔画宽度按 24 框给（环 / 辐 1.8，枢点 r2.2），缩放即等比；**不得**在不同档位改笔画宽度制造「两种标」。

## 与 `--xs-size-glyph-brand` 的关系

- 品牌标**自身不带尺寸**（SVG 无 `width` / `height`，遵守 assets README §3.1 同一条纪律）；边长一律由 token / 宿主给：
  - 首屏页头 / hero 位 → `--xs-size-glyph-brand`；
  - 侧栏品牌位 → `sidebar.brand.mark` 宿主（DSH 侧栏行体系），量级参考 `--xs-size-icon-sidebar`。
- 实现票**不得**把像素值写进组件；若需新档，先回写 token 字典 §10 再取值。

## 品牌名「玄枢」排版位（`sidebar.brand.name`）

- **排版位**：品牌标右侧，与标同基线、同行高；标与名间距 `--xs-space-row`（列表行内水平间距语义）。
- **文字色**：`--xs-text-brand`（品牌名「玄枢」专用 text token，token 字典 §3）。
- **字阶**：沿用 DSH 侧栏品牌位既有字阶（不新造字号档）；**不加粗到标题档、不降档到说明档**——品牌名就是品牌名。
- **窄屏**：侧栏收成图标栏时（S15 §2F），品牌名随 DSH 既有机制退到 tooltip；`main` 面板头仍写字样（`XsPanelHeader`），品牌标 + 名的组合位让位给面板头标题。
- **只换标与名**：`sidebar.brand.mark` / `.name` 是 single 槽、无占用者（S15 §8）；玄枢只替换这两处，不动 DSH 的其余侧栏控件。
