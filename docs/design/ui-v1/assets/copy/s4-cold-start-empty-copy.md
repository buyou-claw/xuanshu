## 逐条说明（与屏稿 §3 对齐）

- **① 命盘卡**（S4 §3 ①）：本屏主角。插画（asset.S4-1）+ 标题「底座还没立起来」+ 一句解释「填一次出生信息，命盘就点亮了」+ 主按钮 `[开始填写出生信息 ->]` + 一行代价说明「预计 1 分钟；之后不再重复录入」。**不做「跳过」按钮**——底座是唯一必填项。
- **② 日课卡**（S4 §3 ②）：必须写出因果——「今天还没有生成日课。日课默认每天 07:30 生成。」两个按钮 `[立即生成]`（底座未立时点了会失败）与 `[改时间 -> S14]`；卡内一行小字「（底座未立时生成会失败）」把结局提前说清。
- **③ 底稿卡**（S4 §3 ③）：文案 = 「底座未立，还没有可提炼的来源。」+「这里不会先有内容：提炼源是 0。」唯一按钮 `[开始填写出生信息 ->]`。底稿卡上**没有 `[刷新]`**（S1 ready 态才有）——这是与 S1 最需要被看清的一处差异。
- **④ 问事格副标题**（S4 §1 / §3 ④）：三格全部可用（工作区 / 工作流不依赖底座）；问事格副标题改为「底座未立 · 会先引导你填出生信息」。

## 空因分流备注（S1 §6，供实现侧判定文案取哪条）

- 命盘卡空因唯一：底座未立（缺出生信息）→ 恒用 ① 主文案。
- 日课卡空因唯一：今日尚无产物 → 恒用 ② 主文案。
- 底稿卡两种空因（S1 §6 ③）：**(a)** 底座未立 → 用 ③ 主文案「底座未立，还没有可提炼的来源。」；**(b)** 底座已立但从未刷新 → 「底稿还没生成过。」+ `[立即刷新]`（本表只定稿冷启动期 (a) 文案；S1 ready 态的 (b) 文案见 S1 §6）。
