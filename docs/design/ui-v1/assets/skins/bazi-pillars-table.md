# 四柱表皮肤（bazi-pillars-table）

> 台账：asset.S2-7 ｜ 类型：texture（组件皮肤）｜ 屏：S2《命盘卡详情》§3③、§4 `XsBaziPillarsTable`
> 用途：四柱表（4×4：年 / 月 / 日 / 时 四列 × 天干 / 地支 / 藏干 / 十神 四行，含缺项占位「—」）。
> 取值纪律：本规格只引用 token 名；一切取值以 `tokens/xs-tokens.css` 为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S2 §4 组件树）

1. **表容器** —— 抽屉正文内的嵌套表块；DSH 表格原语承载（S2 §4）。
2. **列头行** —— 年 / 月 / 日 / 时 四列列头 + 列头装饰位（icons 分工 asset.S2-2，SVG 16×16 ×4 或统一一枚）。
3. **行头列** —— 天干 / 地支 / 藏干 / 十神 四行行头。
4. **数据单元 ×16** —— 只读文本单元。
5. **缺项占位「—」** —— 缺项按「—」显示，不留空白格让人猜（S2 §3③）。
6. **缺项说明行** —— 表块底部一行说明（如「性别未知，大运按男排」）。

## 状态

| 状态 | 呈现 |
|---|---|
| `ready`（常态） | 4×4 全量只读渲染；只展示、不可改（S2 §3④） |
| `loading` | 四柱表 4×4 占位格，走卡级骨架皮肤（skins/skeleton-card.md，S2 §6 loading 行） |
| `error`（结构不符） | 已能读出的部分照常显示 + 一行「部分要点读不出来（<字段名>）」，文字用 `--xs-state-error-fg`；不整屏失败（S2 §6 error(b)） |
| 缺项 | 「—」占位 + 表块底部说明行；**不留空白格**（S2 §3③） |

## 尺寸语义

- 表容器在抽屉正文列内全宽；抽屉宽度语义 = `--xs-size-drawer-width`（宽屏）/ `--xs-size-drawer-maxheight`（窄屏）。
- 四列等宽；单元文字不截断，超长折行。
- 属抽屉正文内滚区的一部分：内滚区最大高度 `--xs-size-scrollregion-max`。

## 备注

- 配套图标：icons 分工 asset.S2-2（列头装饰位）、asset.S2-3（大运展开 / 收起指示，同区联动）。
- 全表只读：无任何排序 / 显隐 / 切换控件（S2 §9「不展示：任何可编辑档位、流派切换、显示显隐开关」）。
