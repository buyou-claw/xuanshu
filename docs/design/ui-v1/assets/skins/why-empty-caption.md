# 「为什么空」说明行排版皮肤（why-empty-caption）

> 台账：asset.S4-7 ｜ 类型：texture（组件皮肤）｜ 屏：S4《自我总览首次空态》§2、§3①②③；S1 各卡 empty 态同型
> 用途：卡内「为什么空」说明行的排版（小字 + 弱化）；排版 token。
> 取值纪律：本规格只引用 token 名；一切取值以 `tokens/xs-tokens.css` 为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S4 §2 / §3 各卡空态）

1. **空态区底** —— 空态整块区域的底，与正常内容区分。
2. **「为什么空」说明行** —— 一句说清为什么是空的（如「底座还没立起来：还缺出生信息。」）；空态写法三要素的第一要素（说清为什么空 + 给下一步 + 指向哪，S4 §7 借精神行）。
3. **代价 / 因果副行** —— 更弱一档的小字（如「预计 1 分钟；之后不再重复录入」「（底座未立时生成会失败）」）；把结局提前说清（S4 §3②）。
4. **下一步动作位** —— 主按钮 / 文字链（排版归位，皮肤分别见 skins/primary-button.md 与 `--xs-text-link`）。

## 逐部位 token 引用

| 部位 | token | 语义 |
|---|---|---|
| 空态区底 | `--xs-surface-empty` | 空态区的底（与正常内容区分） |
| 空态前景（说明文字与图形） | `--xs-state-empty-fg` | 空态前景（说明文字与图形；插画同此前景，illus 分工继承） |
| 「为什么空」说明行 | `--xs-text-secondary` | 次要文字（说明句 / 卡副标题）——小字 + 弱化的主档 |
| 代价 / 因果副行 | `--xs-text-secondary` | 次要文字（说明句）；**#64 起不再用 tertiary**，理由见「副行为什么不用 tertiary」 |
| 指向链接（「改时间 -> S14」等） | `--xs-text-link` | 可跳转文字（跨屏跳转） |
| 说明行↔副行行距 | `--xs-space-stack-sm` | 紧邻文字行之间的垂直距离 |
| 说明行↔动作位行距 | `--xs-space-stack-md` | 控件 / 段落之间的垂直距离 |
| 空态区内边距 | `--xs-space-card-pad` | 卡内边距 |

## 状态

| 状态 | 呈现 |
|---|---|
| `empty`（本皮肤主态） | 说明行 + 副行 + 动作位齐备；每句都指向下一步（S3 / S14 / S6 / S12），**不写「暂无数据」**（S2 §6 empty 行同纪律） |
| 弱化纪律 | 弱化靠 text 族分档（secondary / tertiary），**不靠降透明度、不靠更小字号的自造档**——字阶由 DSH 排版承载，本皮肤只定点名哪一档 |
| 与插画同区 | 插画（illus 分工）在前景区以 `--xs-state-empty-fg` 继承色呈现，说明行排版不与插画抢层级（插画是装饰，文案是主信息） |

## 副行为什么不用 tertiary（#64 / UX-02）

- 判据 **C-003**（对比度达 WCAG AA）按「正文级」量：副行 13px、整句要读，属正文级 → 要 ≥ 4.5:1。
- 实测（浏览器录制 `tests/ux/fixtures/visual-facts.json` · `panel:overview`）：tertiary（bluish-600 `#81858c`）
  落在空态底 `--xs-surface-empty`（`#f5f6f7`）上只有 **3.42:1** —— 正是这一面原先的最低值；
  secondary（bluish-700 `#61666b`）是 **5.36:1**。同页另两处小字（页眉本地数据路径、快捷入口卡脚注）
  在白底上是 3.71:1 → 5.80:1。
- **不把 tertiary 整体调深**：它被全站点名使用（卡脚 info / 时间 / 计数），一改就把所有面的观感一起改，
  超出这张票的范围；也不新增中间色值（token 字典当前没有 bluish-650 档，新增色值要走尺度层并重排字阶，
  见台账 §17.7.2）。所以只把这一处换档到 secondary。
- 代价（记录在案）：说明行与副行现在同色同档，两行之间的层级只剩文案（括号补语）与位置。
  若日后要恢复「再弱一档」，应在字阶重排时一并引入中间档，而不是回到 tertiary。
- 回归守卫：`tests/assembly/overview-contrast.test.mjs`（双模、逐处、按 WCAG 公式现算）。

## 尺寸语义

- 说明行宽 ≤ 卡内容宽；宽屏 ≤ 两行、窄屏一行（S4 §2.2 说明①：窄屏每卡只留一行「为什么空」+ 一个按钮）。
- 行距只走 stack 族两档（`--xs-space-stack-sm` / `--xs-space-stack-md`），不引入第三个自造行距。
- 无图形尺寸（排版规格）；卡最小高度仍守 `--xs-size-card-minheight`。
