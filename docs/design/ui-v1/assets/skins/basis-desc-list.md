# 起盘口径描述列表皮肤（basis-desc-list）

> 台账：asset.S2-6 ｜ 类型：texture（组件皮肤）｜ 屏：S2《命盘卡详情》§3⑥、§4 `XsBasisLineBlock`
> 用途：起盘口径只读行（三行，右侧值列）：`时间算法 = 真太阳时（经度 + 均时差）`、`性别 = 未知（按男排）`、`其余旋钮 = 引擎缺省（本盘未改）`。
> 取值纪律：本规格只引用 token 名；一切取值以 `tokens/xs-tokens.css` 为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S2 §4 组件树）

1. **只读容器** —— 口径三行的只读区；口径行同时是「这盘到底怎么算出来的」的说明书（S2 §3⑥）。
2. **行 ×3** —— 左名目列（时间算法 / 性别 / 其余旋钮）+ 右值列（实际档位措辞）；名目与值同框可见。
3. **行间分隔** —— 发丝分隔线。
4. **（同区联动）缺项说明位** —— 四柱表缺项说明同款小字行（如「性别未知，大运按男排」），口径区复用此排版。

## 逐部位 token 引用

| 部位 | token | 语义 |
|---|---|---|
| 容器底 | `--xs-surface-readonly` | 只读面（内容在场但不可编辑） |
| 容器描边 | `--xs-edge-readonly` | 只读区描边 |
| 容器圆角 | `--xs-radius-nested` | 卡内嵌套面圆角 |
| 名目列 | `--xs-text-secondary` | 次要文字 |
| 值列 | `--xs-text-body` | 正文 |
| 值内档位措辞 | `--xs-text-body`（同值列） | 档位名不另设色、**不得用 `--xs-text-link`**——只读展示，链式色会被误读成可切换（S2 §3⑥：不可在本屏切换） |
| 缺项说明行 | `--xs-text-secondary` | 次要文字（说明句） |
| 行间分隔 | `--xs-edge-divider` | 区块分隔线（发丝） |
| 容器内边距 | `--xs-space-card-pad` | 卡内边距 |
| 行距 | `--xs-space-stack-sm` | 紧邻文字行之间的垂直距离 |
| 名目↔值列距 | `--xs-space-row` | 列表行内的水平间距 |

## 状态

| 状态 | 呈现 |
|---|---|
| 只读常态（唯一态） | 无交互态、无切换控件；允许选择并复制文本（只读操作，S2 §5 第 3 步） |
| `loading` | 口径行 3 行占位，走卡级骨架皮肤（skins/skeleton-card.md，S2 §6 loading 行） |
| `error`（部分要点读不出） | 已读出部分照常渲染 + 一行「部分要点读不出来（<字段名>）」，该行文字用 `--xs-state-error-fg`；不整屏失败（S2 §6 error(b)） |

## 尺寸语义

- 容器在抽屉正文列内全宽；抽屉宽度语义 = `--xs-size-drawer-width`（宽屏）/ 抽屉最大高度 = `--xs-size-drawer-maxheight`（窄屏全屏覆盖）。
- 名目列取内容宽、值列右对齐（S2 §10 台账「三行，右侧值列」）；长值折行不截断。
- 属抽屉正文内滚区的一部分：内滚区最大高度 `--xs-size-scrollregion-max`。
