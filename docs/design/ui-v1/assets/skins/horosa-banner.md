# horosa 未就绪提示条皮肤（horosa-banner）

> 台账：asset.S4-8 ｜ 类型：texture（组件皮肤）｜ 屏：S4《自我总览首次空态》§6 error(a) 行
> 用途：horosa 未就绪提示条（含 `[重新检测]`）：「底座（horosa）没起来：先跑 setup 或看排查」；提示条皮肤 + 图标。
> 取值纪律：本规格只引用 token 名；一切取值以 `tokens/xs-tokens.css` 为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S4 §6 error(a) 行）

1. **提示条容器** —— 全屏顶部一条，在四卡之上；常驻直到重测通过；**不整屏失败**——四卡仍渲染为冷启动形态，用户可先去工作区（S4 §6 error(a)）。
2. **前置告警图标位** —— 告警 / 断连语义图标一枚（行内前置档；icons 分工，与 asset.S3-10 错误族同族）。
3. **文案** —— 「底座（horosa）没起来：先跑 setup 或看排查」。
4. **动作位 ×2** —— `[重新检测]`（就地重测）+ `[去排查 -> S15]`（跳管理入口；S4 §8：本屏只给跳转，不复制排查界面）。

## 逐部位 token 引用

| 部位 | token | 语义 |
|---|---|---|
| 提示条底 | `--xs-surface-card-nested` | 卡内嵌套面（边条式提示条的底） |
| 左侧边条 | `--xs-state-error-fg` | 错误态前景（未就绪 = error 级，S4 §6 error(a)） |
| 前置图标 | `--xs-state-error-fg` | 错误态前景 |
| 文案关键词（「底座（horosa）没起来」） | `--xs-state-error-fg` | 错误态前景（关键词上色，正文保持正文色） |
| 正文 | `--xs-text-body` | 正文 |
| `[重新检测]` / `[去排查 -> S15]` | `--xs-text-link` | 可跳转文字（重测动作与跨屏指路） |
| 提示条圆角 | `--xs-radius-nested` | 卡内嵌套面圆角 |
| 提示条内边距 | `--xs-space-card-pad` | 卡内边距 |
| 图标↔文字↔动作间距 | `--xs-space-row` | 列表行内的水平间距 |
| 提示条与页缘 / 四卡间距 | `--xs-space-page` / `--xs-space-card-gap` | 面板内容与面板边缘的距离 / 卡片之间的栅格间隙 |

## 状态

| 状态 | 呈现 |
|---|---|
| `error`（本皮肤主态） | 常驻展示 + 两个动作位；四卡照常冷启动形态（局部失败不升级成整屏失败） |
| 重测中 | `[重新检测]` 转进行中文案（指示位 `--xs-state-running-fg`）；提示条不闪、不撤 |
| 消解 | 重测通过 → 提示条撤下，按探测结果落定冷启动或 S1 形态（S4 §6 loading 行：一次落定不闪烁） |

## 尺寸语义

- 提示条全宽（面板内容列内）；前置图标边长 `--xs-size-icon-inline`。
- 高 ≈ 一行正文 + 上下内距；动作位不折入「⋯」（重测是主恢复路径）。
- 窄屏同形：动作位折到文案行尾，不隐藏「去排查」指路（S4 §2.2 与 §6 的窄屏纪律：要素不减）。

## 备注

- 与 skins/stale-banner.md（asset.S2-10）同族异义：同为边条式提示条结构，语义色一为 error、一为 stale，**不得混用**；两件的图标位都归 icons 分工（错误 / 陈旧各族）。
- 「底座未就绪」在 S3（error(a)「底座没起来」+ `[去排查 -> S15]`）与 S14（asset.S14-7 空态指向 S3）出现时，复用本皮肤的行内形态与 token 引用，不另起第三套告警样式。
