# 禁用态出盘按钮 + 理由行皮肤（cast-button-disabled）

> 台账：asset.S3-7 ｜ 类型：texture（组件皮肤）｜ 屏：S3《八字冷启动向导》§2.6、§6 禁用态行
> 用途：禁用态出盘按钮 + 禁用理由行；按钮皮肤 + 提示条皮肤。
> 取值纪律：本规格只引用 token 名；一切取值以 `tokens/xs-tokens.css` 与 DSH 主题为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S3 §2.6 线框）

1. **主按钮（置灰）** —— `[确认并出盘]`：置灰、点了也不出盘；**绝不出现**「继续出盘」旁路按钮（S3 §9 缺经纬度口径③）。
2. **理由行** —— 两行结构：第一行「缺：经度 / 纬度。」（缺什么，据实列项）；第二行因果说明「没有经纬度，真太阳时就算不出来；引擎会悄悄退回钟表口径，玄枢不让这种盘生成。」
3. **修复入口 ×2** —— `[去填出生地]`（回第 2 步通道 A）/ `[改用手输经纬度]`（通道 B）；空态必须可执行（S3 §2.6 说明③）。

## 逐部位 token 引用

| 部位 | token | 语义 |
|---|---|---|
| 禁用按钮底 / 描边 | DSH 按钮原语 disabled 形态（`--dsw-alias-*` 既有禁用面，不新造 token） | 禁用按钮由 DSH 原语承载；玄枢不自造禁用底 |
| 禁用按钮文字 | `--xs-text-disabled` | 禁用态文字 |
| 理由行容器底 | `--xs-surface-card-nested` | 卡内嵌套面（提示条形态的底） |
| 理由行容器圆角 | `--xs-radius-nested` | 卡内嵌套面圆角 |
| 「缺：经度 / 纬度。」 | `--xs-state-error-fg` | 错误态前景（阻断性缺失 = 缺经纬度禁止出盘的界面本体，S3 §3.6 / 索引 D6） |
| 因果说明句 | `--xs-text-secondary` | 次要文字（说明句） |
| 修复入口文字 | `--xs-text-link` | 可跳转文字（回跳修复路径） |
| 按钮↔理由行间距 | `--xs-space-stack-md` | 控件 / 段落之间的垂直距离 |
| 理由行内边距 | `--xs-space-card-pad` | 卡内边距 |
| 理由行内行距 | `--xs-space-stack-sm` | 紧邻文字行之间的垂直距离 |
| 修复入口间距 | `--xs-space-toolbar` | 一排控件之间的水平距离 |

## 状态

| 状态 | 呈现 |
|---|---|
| `disabled`（本皮肤主态） | 按钮置灰 + 理由行常驻（缺经纬度时宽 / 窄同形，S3 §2.6 标题）；状态位同步显示「缺经纬度（禁用）」（skins/birth-confirm-table.md） |
| 修复后 → `ready` | 经纬度补齐 → 理由行撤下、按钮恢复主按钮皮肤（skins/primary-button.md）；**不做「置灰但能点」的假禁用** |
| 未勾选核对 → `disabled` | 同形复用：理由行换「先勾选『以上信息我已核对』」，不给修复入口（勾选即修复，S3 §6 禁用态行） |

## 尺寸语义

- 按钮高 = `--xs-size-control-height`；按钮宽按主按钮语义（宽屏按内容宽，窄屏随吸底条全宽，见 skins/sticky-bottom-bar.md）。
- 理由行 ≤ 两行正文 + 一行修复入口；容器随表单列宽（≤ `--xs-size-panel-content-max`）。

## 备注

- 本皮肤是「缺经纬度禁止出盘（防静默退化）」的界面本体（S3 §9）：宁可不出盘，也不产出静默退化为钟表口径的盘。
- 与 S4-8 / S2-10 的提示条同族但不同义：本件是「禁用理由 + 修复入口」的组合提示，语义色走 error；stale / horosa 两条各走 stale / error，互不混用。
