# 出生信息确认表皮肤（birth-confirm-table）

> 台账：asset.S3-6 ｜ 类型：texture（组件皮肤）｜ 屏：S3《八字冷启动向导》§2.5、§4 `XsBirthConfirmTable` / `XsClarificationGate`
> 用途：确认表（5 行 + 每行 `[改]`）：出生时间 / 出生地 / 时区 / 时间算法 / 性别。
> 取值纪律：本规格只引用 token 名；一切取值以 `tokens/xs-tokens.css` 为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S3 §2.5 线框与 §4 组件树）

1. **表容器** —— 第 5 步「确认你的出生信息（澄清闸）」的卡面容器。
2. **确认行 ×5** —— 左名目列（出生时间 / 出生地 / 时区 / 时间算法 / 性别）+ 值列 + 行尾 `[改]`（回跳对应步）；窄屏 `[改]` 右对齐、五行等高（S3 §2.5 窄屏说明①）。
3. **不确定项勾选项区** —— 「出生时间只精确到分钟」「出生地是大概位置」两枚勾选，写进 `clarification_notes`；窄屏仍逐条列出、不能折叠（S3 §2.5 窄屏说明②）。
4. **澄清闸勾选项** —— `[x] 以上信息我已核对`，是出盘按钮的解锁条件（S3 §3.5③）；人工确认闸门的界面落点。
5. **状态位** —— 右下角固定显示「可出盘 / 缺经纬度（禁用）」，让禁用态在点之前就能看见（S3 §3.5④）。

## 状态

| 状态 | 呈现 |
|---|---|
| `ready`（可出盘） | 澄清闸已勾 + 五项齐全 → 状态位「可出盘」（`--xs-state-ready-fg`），出盘按钮解锁 |
| `disabled`（缺经纬度 / 未勾选核对） | 状态位「缺经纬度（禁用）」（`--xs-state-error-fg`）；出盘按钮置灰，禁用形态见 skins/cast-button-disabled.md |
| 澄清闸拦截回问 | 就地展开「底座需要你确认」区（S3 §2.7）：底座回问原文展示（不转述）+ `[回答并重新出盘]` / `[改出生信息]`；回问区容器同走 `--xs-constraint-human-gate-*`（人答的控件区） |
| 出盘 `loading` | 按钮转进行中、表单只读；确认表内容不空、不清场（S3 §6 loading 行） |

## 尺寸语义

- 表容器宽 ≤ `--xs-size-panel-content-max`（面板内容最大宽度）。
- 行高 = 一行正文 + `--xs-space-stack-sm`；窄屏五行等高（S3 §2.5 窄屏说明①）。
- 出盘按钮高 = `--xs-size-control-height`；窄屏时按钮进吸底操作条（skins/sticky-bottom-bar.md）。

## 备注

- 本表是「澄清闸」的界面本体（S3 §9 口径行）：`[x] 以上信息我已核对` 是出盘解锁条件；**绝不出现**「继续出盘」之类的旁路按钮。
- 配套：skins/cast-button-disabled.md（asset.S3-7，禁用态出盘按钮 + 理由行）、skins/sticky-bottom-bar.md（asset.S3-12，窄屏吸底）；icons 分工 asset.S3-5（时区自动 / 手动覆盖标记）落在时区行的值列。
