# 卡级骨架屏皮肤（skeleton-card）

> 台账：asset.S1-10 ｜ 类型：texture（组件皮肤）｜ 屏：S1《自我总览》§6 loading 行、§4 `XsCardStateShell`
> 用途：卡级骨架屏（四卡共用，简化为 2–4 条占位）。
> 取值纪律：本规格只引用 token 名；一切取值（色 / 尺寸 / 时长）以 `tokens/xs-tokens.css` 与 DSH 主题为权威，本文件不含字面值、不含代码。

## 结构拆解（对应 S1 §4 组件树）

1. **卡壳** —— 与 `ready` 态同一张卡面（骨架不换底、不换描边），由 `XsCardStateShell` 承载，保证四卡三态形态一致。
2. **卡头占位条** —— 卡头标题位一枚短条；有徽标的卡（命盘 / 底稿）在卡头右侧再加一枚徽标占位。
3. **正文占位条 ×2–4** —— 按卡定数，与台账「简化为 2–4 条占位」一致：
   - 命盘卡：四柱位 4 个方块占位 + 口径行 1 行占位（S1 §6 命盘卡 loading 行）；
   - 日课卡：宜 / 忌 / 流日 3 行占位；
   - 底稿卡：2 行占位 + 徽标占位；
   - 快捷入口卡：不适用（静态组件，随面板一同渲染，S1 §6 ④ 显式说明不设骨架）。
4. **扫光层** —— 覆盖在占位块上的单向扫光；是增强层，不是可读性的来源。

## 逐部位 token 引用

| 部位 | token | 语义 |
|---|---|---|
| 卡壳底 | `--xs-surface-card` | 卡面（与 ready 态同一底，骨架不另设色） |
| 卡壳描边 | `--xs-edge-card` | 卡的描边 |
| 卡壳圆角 | `--xs-radius-card` | 卡片圆角 |
| 占位块底 | `--xs-surface-skeleton` | 骨架屏占位块底 |
| 占位块圆角 | `--xs-radius-nested` | 卡内嵌套面圆角（比卡小一档） |
| 扫光 / 加载前景 | `--xs-state-loading-fg` | 加载态前景（骨架 / 扫光 / 转圈） |
| 卡内边距 | `--xs-space-card-pad` | 卡内边距 |
| 占位条间距 | `--xs-space-stack-sm` | 紧邻文字行之间的垂直距离 |
| 扫光时长 | `--xs-motion-duration-fast` | 快动效时长语义 |
| 扫光缓动 | `--xs-motion-ease-standard` | 标准缓动 |

## 状态

| 状态 | 呈现 |
|---|---|
| `loading`（本皮肤主态） | 卡壳 + 占位条 + 扫光；单卡进出，不整页转圈（S1 定案 D2：卡级骨架） |
| 减少动态效果偏好 | 扫光静止、只留 `--xs-surface-skeleton` 静态底色（对齐 token 字典 §11 前提：自研扫光必须尊重该偏好） |
| 进出切换 | `loading → ready / empty / error` 一次落定，不闪中间态（S4 §6 loading 行同此纪律） |

## 尺寸语义

- 卡最小高度：`--xs-size-card-minheight`（语义「≈ 2 行 + 卡头」），骨架期同样守住，避免三态切换时卡高跳动。
- 占位条高度：对齐正文一行高的语义（由排版行高承载，不单独造 token）；徽标占位高度 = `--xs-size-chip-height`。
- 四柱方块占位：四枚等宽方块，横向间距 `--xs-space-row`（列表行内水平间距语义）。
