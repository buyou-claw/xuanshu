### 3.4 与侦察报告 `docs/research/horosa-web-windows.md` 的出入（以源码为准）

- **与侦察报告 §4.3 不一致：两列网格的列数写法**。源码是 `grid-template-columns: repeat(min(N, 2), minmax(0, 1fr))`（`components/aianalysis/chat/BestOfCards.js:28`），报告写 `repeat(min(N,2), 1fr)`；`minmax(0, 1fr)` 的防溢出语义要保留。
- **与侦察报告 §4.3 不一致：候选状态栏的字段组合**。实际为 `生成中` / `失败` / `{字数} 字`，**后面按有值才追加**「 · {x.x}s」「 · ${cost}」（`:35`）；报告写「N 字 · 耗时 · 估价」，读起来像三项恒显。
- **与侦察报告 §4.4 一致但需补：判官「槽空=跟随当前模型」的完整回落链**是「档案找不到回落当前档案，模型缺回落当前模型」，返回 `routed:false`（`utils/aiModelRouting.js:68-79`）。
- **与侦察报告 §4.4 一致但需补：`requestStructuredWithFallback` 是三级降级**（正常 → 代理层 HTTP 400 的 `json_schema→json_object→删键` → **前端空正文重发**），报告只写了前两级。第三级的行号是 `utils/aiStructuredOutput.js:115-133`。

## 4. 不搬代码的边界

### 4.1 本索引提供什么、不提供什么

- **提供**：交互点 → 上游 `路径:行号` → 规格要点 → 玄枢照抄/裁剪/偏离 的判定。写稿人写「第 7 节」时**直接引本文件的表行**（屏 ID + 本文件行号即可），不必再回源码。

- **落地方式**：玄枢侧一律 `xs` 前缀自研组件 + DSH 原语（README §3.2），宿主能力（模型调用 / 审批 / 定时）走 DSH 槽位（见 [`DSH槽位映射.md`](DSH槽位映射.md)）。
