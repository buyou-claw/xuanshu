**用户任务通过。** 从自我总览发现侧栏「藏」，从藏库空态打开登记抽屉。无效路径显示原因并禁用登记，注册表不存在。把路径改成真实的合成笔记，填写签后登记。随后在同一 home 的真实应用进程重启后，关闭「稍后配置」提示，从侧栏重新找到同一张卡片并用「木工」搜索。登记前后的注册表由执行器直接读取，重启前后同一条记录的 ID、路径、签和 SHA256 一致。

## 发现与复现

### EXP-001 · 确认 Bug · 文件登记缺少「选择文件…」

[S11 §2【B】①、§4、§5](screens/S11-藏库.md)要求登记抽屉能选择文件或文件夹。实际抽屉只有「选择文件夹…」，文案让文件用户粘贴路径。粘贴路径可以完成任务，用户需先从别处取得路径。该结论指向缺失的入口，不涵盖系统选择器能否正确工作。抽屉截图（`scout-02/screens/007-1.png`）

选定的三步复现轨迹在新 home 命中 **2/2**。缩减去掉填写名称，保留启动后点击「稍后配置」的前置，以及点击「登记第一个藏」这一打开抽屉的触发动作。最短候选为「侧栏 藏 → 登记第一个藏」。只保留触发动作时，界面仍在自我总览且登记按钮不可达。两步候选在独立 home 中命中 **2/2**。最短性只覆盖保留该触发动作的原轨迹子序列；初态与藏库空态的快照均显示抽屉尚未打开。加上环境指纹核对后，两步路径再次命中 **2/2**。重放结果（`picker-replay/replay.json`） · 缩减后截图（`picker-replay/05-confirm/screens/006-1.png`） · 最终复核（`picker-final-smoke/replay.json`）

**回归场景**。在空注册表、同样首跑条件下，按最短路径打开登记抽屉。断言同一可见抽屉中有可用、可键盘到达的「选择文件…」和「选择文件夹…」；打开与取消文件选择不产生登记，选择合成文件只回填指针。最小界面断言为文件选择按钮可见且启用，现版稳定违背可见断言。系统选择器操作留到实现之后验收。

### EXP-002 · 间歇问题 · 应用重启后根界面有时空白

首次重启后 HTTP 和身份握手成功，注册表哈希不变。Edge 根界面空白，普通刷新未恢复，控制台出现根槽的 `SlotAssemblyError`。第二次重启曾显示导航，但模型提示遮挡侧栏，之后又出现空白和另一种 `SlotAssemblyError`。第三次重启后及时关闭模型提示，成功进入藏库并按签找回。Windows 运行器终止了自己启动的进程树，优雅退出和宿主装配竞态尚待对照，现有证据不足以归因。

独立重放保留了登记前置、进程重启和浏览器刷新，检查根槽错误、导航不可见、注册表仍有一条记录。两个新 home 的有效复跑均未命中同一指纹，导航可见且磁盘记录存在。已保存重放证据，未得到稳定最短路径。重启重放（`restart-replay/replay.json`） · 主样板控制台（`scout-02/console.jsonl`）

### 其他观察

- **自动化缺陷**。Playwright 默认找不到系统级 Edge，改用本机已安装的 Edge 路径恢复。首次验登记成功时，精确正文定位遗漏了标题里的「已登记」，实际卡片已出现。改用观察到的完整可访问标题后核实成功。启动失败（`scout-01/steps.jsonl`） · 定位器误判（`scout-02/screens/020-1.yml`）
- **体验启发式发现**。纯本地登记也先遇到「添加一个 API Key 开始使用」。用户可以点「稍后配置」继续。本轮只记录它对离线任务增加的一步。首跑截图（`scout-02/screens/001-1.png`）
- **需要人工判断**。空态的说明、搜索和主操作的视觉层级留给 [L-001](criteria/README.md) 人工复核。藏库空态截图（`scout-02/screens/005-1.png`）
