> 本屏不做什么：**不挂谱**（谱在 S6 里勾选，两者对象不同、措辞不同）；不做工作区 / 工作流的创建与编辑（DSH 原有界面 / S12）；不做自动扫描沉淀（那是另一条机制，只进底稿）；不做裁剪算法的实现（只做披露）

## 1. 目的与入口

- **从哪进**：**会话面板（DSH `conversation`）输入区上沿的 `[临时挂载]` 按钮**；会话状态栏 `挂载 N 字 / 预算 M 字`（点击重开本抽屉看账本）；`consult` 面板（书房门厅）的挂载入口同样开这一个抽屉。
- **去哪出**：S6（确认后回到会话，状态栏即刻更新）；DSH 原有工作区界面（想改工作区内容时去那边，本屏不改）。
- **相邻屏**：S6（宿主）、S9（合参候选的截断护栏也吃同一条预算口径，见 §7）、S12 工作流创建向导（工作流的来源）、S15（数据目录说明）。
- **本屏一句话**：把某个具体的工作区 / 工作流作为**本次上下文**临时引进来，并在注入前把「拿了什么、砍了什么、还剩多少」摊开给人看。

**线框说明**：① 抽屉顶部常驻边界句：对象是工作区 / 工作流，**谱不在这里**（C6 的一半：两处各带一句边界说明）。② 工作区分区——列的是 DSH 原有工作区（只读引用，带路径与文件数、最近改动时间），勾选即选入本轮；不提供「新建工作区」入口（那种事去 DSH 原界面）。③ 工作流分区——列已创建的工作流及其产出（skill 名 / 时间）。④ 「本轮挂载上下文（预览）」折叠区：按**层**列出将被注入的内容，每层一枚 Tag（`纳入` / `已裁剪 raw→kept 字` / `超预算未纳入`）——这是 C7 的账本位；折叠记忆按 **H2**（新出现的层默认展开、用户手动收起过的保持收起，按层记忆、不整块重置）。⑤ 状态栏 `挂载 N 字 / 预算 M 字` 固定在底部动作条左侧，与 S6 输入区下沿同一口径；右侧 `[取消]` / `[确认挂载到本轮]`。

## 5. 交互流程

1. **打开抽屉**：触发 = S6 `[临时挂载]`（或点状态栏）→ 系统列 DSH 工作区与已创建工作流（**只读枚举，不写盘、不调 LLM**）→ 界面 `loading` → `ready`（或 `empty`）。
2. **选对象**：触发 = 勾选某个工作区 / 工作流 → 系统读该对象的内容清单与体积（只读扫描；**不写入**任何文件）→ 预览区逐层出现：先「读取中」，再落 Tag。
3. **算预算**：系统按当前模型的上下文窗口实算预算 M，与本次装配总量比对 → 状态栏 `挂载 N 字 / 预算 M 字`；超预算则进入裁剪：**按段边界公平裁剪**，或对无法裁剪的层**整层丢弃** → 预览区打 Tag（`已裁剪 raw→kept` / `超预算未纳入`）。
4. **核查账本**：触发 = 展开某层 → 看「保留 / 裁掉」明细（按段）；层的展开 / 收起状态**按层记忆**（H2：新出现的层默认展开，人手动收起过的保持收起）；触发 = `[缩小挂载范围]` → 取消某些勾选并**重新预览**（回到步骤 2）。
5. **确认挂载**：触发 = `[确认挂载到本轮]` →【副作用】写会话 meta `mounts`（与 `pus` 并列、互不混淆）→ 抽屉关闭，S6 状态栏与上下文摘要同步更新。
6. **取消**：触发 = `[取消]` / Esc / 点遮罩 → 不写盘；若已改过勾选，提示一次「已选但未确认，本轮不会挂载」。
7. **发送时注入**：触发 = S6 发送消息 → 按**已确认的裁剪结果**注入 system prompt 稳定层，并在注入内容里注明裁剪（「此处裁去 N 字」/「N 层因超预算未纳入」）→ 界面无额外弹窗，账本可随时从状态栏重开。
8. **陈旧检测**：触发 = 打开抽屉时发现某已挂对象的内容清单变了（文件新增 / 修改）→ 该层标 `stale` + `[重新预览]`；**不静默沿用旧账本**。

## 6. 关键状态

| 状态 | 什么时候 | 界面是什么样（可执行） |
|---|---|---|
| `empty` | 既没有工作区也没有工作流 | §2.4：为什么空 + `[去 DSH 工作区 ▸ 原有界面]` + `[创建工作流 ▸ S12]` + `[只带谱问一次 ▸ S6]`；并重申「谱不需要在这里挂」 |
| `loading` | 打开抽屉 / 选中对象后读内容 | 分区行骨架；预览区逐层出「读取中」；**状态栏先显示预算 M**（模型窗口已知，字数待算），避免底部跳动 |
| `error` | ①某工作区路径不存在 / 权限不足 ②工作流清单读不到 ③预算换算拿不到模型窗口 | ①该行标 error + `[移除该对象]` + `[去 DSH 工作区界面]`，其余对象照常可挂；②工作流分区降级为「清单读不到」+ `[重试]`，工作区分区不受影响；③状态栏写 `挂载 N 字 / 预算未知`，并给 `[去 DSH 设置看模型配置]`，**不假装有预算** |
| 超预算态 | 装配总量 > 预算 | §2.2：至少一层 `超预算未纳入`；状态栏补「已纳入 N / M 层」；给 `[缩小挂载范围]` 与去 S9 的口径链接 |
| 已裁剪态 | 某层被按段裁剪 | §2.3：`已裁剪 raw→kept 字` + 可展开「保留 / 裁掉」；注入文案注明裁去字数 |
| `stale`（陈旧） | 已挂对象内容在预览后变化 | 该层标 `stale` + `[重新预览]`；S6 状态栏同源提示「挂载内容已变化」 |
| 禁用态 | 还没开会话（从别处误开抽屉） | 抽屉打开但只显示一行：「临时挂载属于某一次问事；先开一次问事（去 S6）」，选择控件禁用 |
| 窄屏态 | <1100 | §2.5：占满宽、分区折叠、状态栏与动作固定底部 |
