> 归属票：14 ｜ 层级：main 面板 ｜ 槽位：main key `cang` + `sidebar.panellist` 行（`id: cang`、`order: 50`、`label: 藏`；**无分组字段** —— 定案 D7）——键名以 `shared/DSH槽位映射.md` 为准
> 上游依据：`docs/specs/001-assembly-foundation.md` §Implementation Decisions「藏库」（用户故事 29-30）；`docs/architecture-v1.md` §5/§7；`.scratch/assembly-foundation/issues/14-cang-registry.md`；`docs/adr/0003-assets-never-touch-ai.md`（全文）；`xuanshu-portrait.md`「谱 vs 藏」
> 规格级复用来源：无（藏是玄枢自有子系统；「以系统默认程序打开」是**能力复用** DSH 的 open-in-app，非上游规格复用）
> 本屏不做什么：不做检索、不生成摘要、不预览内容、不把藏带进任何会话上下文；**不读、不索引、不分析所登记的文件**。

---

## 1. 目的与入口

**它解决什么**：把「你自己的、永不上 AI 的本地既有文件」（书、文章 / 视频 / 网页、收藏夹、密码…）收成**一个统一入口**——只登记**指针 + 签 + 跳转**，绝不读内容（ADR-0003 是安全不变式，不是偏好）。

**从哪进**：
- 侧栏行「藏」（main key `cang`，轮位 order 50；D7：`sidebar.panellist` 无分组字段，所以不再写「库 · 藏」前缀）；落位见 S15。
- S1 自我总览的快捷入口里**不放藏**（藏是管理入口，不是首屏信息）；S1 只在「库」相关入口处给一行文字入口（跳本面板）。

**去哪出**：
- 卡片 `[以默认程序打开]` → 交给系统默认程序（离开玄枢界面）。
- 卡片路径 → 复制路径 / 在文件管理器中显示。
- 与谱的分界 → 一行说明 + 跳 S5（谱管理）；与挂载的分界 → 一行说明 + 跳 S8（临时挂载账本）。

**相邻屏**：S5（谱）、S8（临时挂载）、S15（入口落位 + C11 数据与拷走）。

**一句话边界**：藏**不是**谱——谱会被 AI 读进上下文，藏永远不会；所以藏库里没有搜索、没有摘要、没有任何「让 AI 看看」。

## 2. 线框

【A】藏库主面板（宽 ≥1100）

```

│ ③ [登记藏]    (搜藏名 / 签)   [签 ▾ 全部]   [排序 ▾ 最近登记 · 名称]
│
│ ④ 按签分组（未贴签的归入「未贴签」）
│   ▾ 签「书」（12）
│     ┌──────────────────────────────────────────────────────────────────────────────

│     └──────────────────────────────────────────────────────────────────────────────
│   ▾ 签「密码」（3）              …

└────────────────────────────────────────────────────────────────────────────────────

**线框说明（A）**：① 是**常驻声明**：贴在面板顶部、不折叠、不可关闭、滚动时吸顶（`sticky`），措辞固定为「藏永不进 AI：只登记指针、签与跳转 —— 玄枢不读、不索引、不分析、不进上下文」。② 一行分界说明（谱 vs 藏 / 谁进 AI），是本屏的语义锚点。③ 三个工具：登记、搜索（**只搜藏名与签这两列**，不搜内容——内容根本不在本地索引里）、筛选与排序。④ 按签分组（签为空归「未贴签」）；分组标题显示条数。⑤ 卡片头部：名称 + 签 + 登记状态。⑥ 五个动作全部是**本地/系统动作**。⑦ 负向声明（评审验点）。⑧ 页脚把注册表路径与「不存内容」摆出来。

【B】登记藏（抽屉）

```
┌─ 登记藏 ───────────────────────────────────────────────────────────────────────────
│ ① 选择本地文件夹 / 文件   (路径)     [选择文件夹…]  [选择文件…]
│    · 系统选择器只取指针：玄枢不复制、不移动、不修改所选内容

│ ③ 签    (输入)   [已有签：书] [资料] [密码] [+ 新建签]

**线框说明（B）**：① 用系统目录 / 文件选择器取指针（**能力复用** DSH 的 directory-picker，不自建选择器）。②③ 名称与签是登记信息，写进注册表；**签是本票要求的一部分**（登记 = 指针 + 签 + 跳转）——注意这只启用**藏的签**，谱的 `tags` 仍未启用（那不在本稿）。④ 跳转入口登记时勾选，决定卡片上出现哪些动作。⑤ 指针校验的边界写得明明白白：只验路径可达，**不读内容**。⑥ 隔离检查是 ADR-0003 在界面上的落地：藏不能指向谱目录。⑦ 人点才登记。

## 3. 线框说明

- ① 常驻声明 — 位置固定在面板顶部第一行，`sticky`；文案逐字固定；不可关闭（没有 × 按钮）。
- ② 分界说明 — 一句话讲清「谱进 AI / 藏不进」，并提供跳 S5 的链接。
- ③ 工具行 — 登记 / 搜索（限藏名 + 签）/ 签筛选 / 排序。

- ⑦ 卡片负向声明 — 明确列出卡片上**没有**的 AI 动作（评审验点）。
- ⑧ 页脚 — 注册表路径（只读）+ 「不存内容」。
- 登记抽屉 ①–⑦ — 指针（系统选择器）/ 名称 / 签 / 跳转入口 / 指针校验 / 隔离检查 / 登记。

## 5. 交互流程

1. 人从侧栏「藏」进入（触发：选中行）→ 系统读 `~/.dsh/xuanshu/cang/registry.jsonl` → 界面：`loading` → `ready`（按签分组列表）。**【副作用】** 无（纯读）。
2. 人点 `[登记藏]`（触发：按钮）→ 界面：登记抽屉打开，状态 `ready`。
3. 人选文件夹 / 文件（触发：系统选择器，**【副作用】** 仅取指针）→ 界面：路径回填，跑指针校验（`存在` / `可访问`），并跑隔离检查。
4. 隔离检查不通过（路径在 `~/.dsh/xuanshu/pus/` 之下）→ 界面：`error`，`[登记]` 禁用 + 说明「谱会被 AI 读取，藏必须与谱安全隔离」。
5. 人填名称、签、勾选跳转入口 → 点 `[登记]`（触发：按钮，**【人工确认闸门】** 在此步，因为登记会写盘）→ **【副作用】** 追加一行到 `~/.dsh/xuanshu/cang/registry.jsonl`（JSONL，append-only）→ 界面：抽屉关闭，列表刷新，新卡片高亮一次。
6. 人点卡片 `[以默认程序打开]`（触发：按钮）→ **【副作用】** 调系统默认程序打开该路径（玄枢不传内容、不做转换）→ 界面：无变化（焦点离开玄枢）。
7. 人点 `[编辑登记]` → 改名称 / 签 / 跳转入口（**不改指针指向的文件**）→ `[保存]` → **【副作用】** 重写注册表对应行；`[重新定位]` 用于指针失效时改路径。
8. 人点 `[移除登记]`（触发：按钮，**【人工确认闸门】** 二次确认「只从藏库移除登记，不会删除你的文件」）→ **【副作用】** 从注册表移除该行 → 界面：卡片消失；**明确不删除、不移动、不修改原文件**。
9. 指针校验发现文件被移动 / 删除 → 卡片转 `stale`：`指针失效` + `[重新定位]` / `[移除登记]`；**不自动扫描磁盘去猜新位置**。

## 6. 关键状态

| 状态 | 触发条件 | 界面表现 | 可执行动作 |
|---|---|---|---|
| `empty` | 注册表为空 / 只有空行 | 空态：声明栏仍在最上；正文写「为什么是空的：你还没有登记任何藏。藏只登记指针，不复制文件」+ 主按钮 `[登记第一个藏]` + 次按钮 `[看看谱和藏的区别（跳 S5）]` | 登记 / 跳 S5 |
| `loading` | 面板首开、读注册表 | 卡片位骨架屏（声明栏**先出**，不等数据） | 无 |
| `ready` | 注册表读取成功 | 分组列表 | 全部卡片动作 |
| `error` | 注册表读写失败 | 明写失败文件与原因 + `[重试]`；只读失败时不给「登记」（避免写坏） | 重试 |
| `stale`（陈旧） | 指针失效（文件被移动 / 删除 / 无权限） | 卡片打 `指针失效` 标记 + 最后校验时间 | `[重新定位]` / `[移除登记]` / `[打开（仍尝试）]` |
| `disabled`（禁用） | 登记抽屉里路径不合规（在谱目录下 / 不存在） | `[登记]` 置灰 + 一行说明缺什么 | 改路径 |
| 窄屏态 | 宽 <1100 | 单列；声明栏不折叠；次要动作收进 `[⋯]` | 同 `ready` |

## 9. 硬约束在 UI 上的呈现

本屏矩阵（README §5）：**C3 ●**、**C6 ○**、**C11 ○**；其余不涉及。

**C3 藏不可见 AI**
- 顶部**常驻**一行（吸顶、不折叠、无关闭按钮）：「藏永不进 AI：只登记指针、签与跳转 —— 玄枢不读、不索引、不分析、不进上下文」。
- 卡片上**没有任何 AI 动作**：卡片只有 `[以默认程序打开] [显示所在位置] [复制路径] [编辑登记] [移除登记]`；卡片上明确写一行负向声明：「本卡没有：摘要 / 问答 / 「让 AI 看看」/ 加入上下文 / 挂载到会话」。
- 机制层同样不存在入口：本屏不注册会话槽、不写会话 meta、不提供「加入上下文」；搜索只覆盖藏名与签两列（内容不在索引里，因为**没有索引**）。

- token：`--xs-constraint-noai-fg/-bg` **只用于那句常驻声明**；**不得**用它给任何「AI 动作按钮」上色（那等于承认按钮存在）。

- 藏库列表**不出现**工作区 / 工作流条目，也不出现谱条目（谱在 S5）。

**C11 一切数据本地、可整体拷走（○ 涉及处）**
