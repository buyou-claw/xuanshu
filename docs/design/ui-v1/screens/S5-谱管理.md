### 2.1 宽（≥1100，默认）· 列表

```
┌ 谱管理 ──────────────────────────────────────────────────────────────────
│ [搜索 名称/描述/正文            ]  级别 [全部 ▾]  来源 [全部 ▾] [＋ 创建新谱]
├──────────────────────────────────────────────────────────────────────────
│ ① 基础输入级 base · 2 个 · 进底稿提炼源 · 级别≠必填（所有谱都非必填）
│  🔒 底座（八字） base · 只读 · 由出生信息与底座生成  [打开] ⓘ改它去重新录制
│     人生经历       base · manual · 10-08 更新     [带去问事][打开][编辑] [⋯]
│ ② 可选输入级 optional · 3 个 · 底稿不采 · 问事时按需追加
│     软件开发       optional · ai-assisted · 10-11 [带去问事][打开][编辑] [⋯]
│     3D 打印        optional · manual · 10-09       [带去问事][打开][编辑] [⋯]
│     生活           optional · sediment · 10-11     [带去问事][打开][编辑] [⋯]
│ ③ 边界说明：本列表只收谱。工作区 / 工作流与谱并列独立、不是谱，只会在问事的
│    「临时挂载」里出现（去 S8）；你自己的本地文件在藏库里（去 S11），永不进 AI。
└──────────────────────────────────────────────────────────────────────────
```

**线框说明**：① base 分组头——组名 + 计数 + 取用规则（进底稿提炼源）+ 「级别≠必填」常驻一句，消掉「base = 必填」的误读；分组不可折叠成默认收起（谱数量少，收起反而多一次点击）。② optional 分组头——同一版式，规则换成「底稿不采 · 问事时按需追加」。③ 列表底部常驻边界说明一行，是 C6 的可见落点；`🔒 底座（八字）` 是 C5 的锁定行在谱侧的镜像（本节与 S6 的锁定行用同一套标记：「锁定行 · 默认在场 · 不可关」，此处额外标只读）。行内动作：`带去问事` = 预勾选并跳到 S6（不改盘、只带状态）；`打开` = 详情；`编辑` = 直接改 MD；`⋯` = 「删除 / 复制谱名 / 打开所在目录」。搜索框匹配三类文本（谱名 / manifest 概览 / 内容文件正文），筛选按 `level` 与 `source`。

### 2.2 宽 · 详情（点「打开」后，列表收成左列）

```
┌ 谱管理 / 软件开发 ───────────────────────────────────────────────────────
│ [← 返回列表]        名称 软件开发   级别 (基础输入 ○)(可选输入 ●)   [保存]
├───────────────────────────────┬──────────────────────────────────────────

│  一段话说明这个谱是什么、覆盖   │   ## 概况
│  哪些内容。人可编辑。           │   …（一级标题 = 固定字段结构，各谱自定）
│                                │   ## 用到的工具
│ ③ 汇总 summary.md（AI 快速定位）│   …
│  精简汇总；人可改（与底稿相反） │
│  [重建 summary（AI 提炼）]      │ ④ 元信息（只读）：spec pu/1 · source
│                                │    ai-assisted · updated_at 10-11 · 签 预留
└───────────────────────────────┴──────────────────────────────────────────
```

**线框说明**：① 描述 = manifest 概览，是 AI 优先读的那段，人可编辑；② 细节 = 内容文件的分节正文，一级标题即固定字段结构；③ summary 面板单列，明确写「人可改」（与底稿「纯派生不可手改」相反，防两类规则互相污染），「重建 summary」是 AI 提炼动作、结果仍要人保存；④ 元信息只读展示 frontmatter 的 `spec / source / updated_at` 与「签 · 预留字段 · 暂不启用」（`tags` 不进入任何交互）；级别用两枚开关式按钮表示（`base` / `optional`），旁挂一行后果说明。

**线框说明**：① 输入不限（打字 / 附件；语音 v2）；② 谱名即目录名，做 slug 化与唯一性校验，并把「预览：`pus/<谱名>/`」直接显示出来（列表不写绝对路径）；③ AI 转换中（`running`）必须有 `[中断]`，中断后中间产物只留临时目录、绝不半成品落 `pus/`；④ 预览 = 名称 + 描述 + 细节 + summary 四块，级别可在这里改；⑤ 「确认落盘」是【人工确认闸门】，落盘后才在列表出现新谱。步骤条两侧的「← / →」在当前步之外不可点击（禁止跳步）。**承载方式**：这 5 步是**面板内的自研视图切换**（DSH 无框架级子页槽，`shared/DSH槽位映射.md` §7「S5」），不新开面板、不弹居中模态；**同结论佐证**：`S15:62`/`:117`/`:187` 同样登记为「`pus` 面板内的自绘视图切换（面板内子页）——不新增 main key、不进 `shell.overlay`、不用居中对话框」，与本稿一致（见 §8）。

## 5. 交互流程

1. **进入列表**：触发 = 侧栏「库 → 谱」/ S6「管理谱」/ S10「查看」→ 系统读 `pus/*/manifest.md` 与各文件 mtime（不调 LLM、不写盘）→ 界面 `loading` → `ready`（按 `level` 分组；`manifest` 解析失败的谱单独进 error 行）。
2. **搜索 / 筛选**：触发 = 输入或选筛选 → 系统在本机索引上过滤（名称 / 描述 / 正文；`level`、`source`）→ 界面 `ready`；无命中时切「没有匹配的谱」空态变体（按钮 `[清空筛选]`、`[＋ 创建新谱]`）。
3. **点开谱**：触发 = 行「打开」→ 系统读 `manifest.md` + 内容文件 + `summary.md` → 界面 `loading` → `ready`（详情三块 + 元信息）。
4. **编辑保存**：触发 = `[编辑]` → 改文本 → `[保存]` →【人工确认闸门】若正文与 summary 都动过，弹一次「影响面」说明（会不会进底稿、要不要重建 summary）→【副作用】**写入（落盘）** `manifest.md` / 内容文件 / `summary.md` → 界面 `ready`，行内 `updated_at` 刷新。
5. **改级别**：触发 = 详情里切换级别 →【副作用】只改 frontmatter `level` → 界面提示「底稿提炼源变更 · 下次底稿刷新生效（去 S13）」（base→optional 与反向各一句文案）。
6. **重建 summary**：触发 = `[重建 summary（AI 提炼）]` →【副作用】调 LLM 生成候选 summary（**不自动写盘**）→ 界面 `running` → `ready`（候选进编辑器，人点 `[保存]` 才落盘）。
7. **创建新谱**：触发 = `[＋ 创建新谱]` → ① 打字 / 附件 → ② 定义谱名（slug 化 + 唯一性校验）→ ③【副作用】AI 转换（内置 `xuanshu:create-pu` skill 借 DSH coding 工具；中间产物落临时目录，可 `[中断]`）→ ④ 生成预览（名称 + 描述 + 细节 + summary，可改级别）→ ⑤【人工确认闸门】【副作用】写 `pus/<谱名>/` → 回列表，新谱出现在对应级别分组。
8. **删除谱**：触发 = 行 `⋯ → 删除` →【人工确认闸门】二次确认（要求输入谱名确认，文案写明「皮之不存：底稿下次刷新会去掉这一路来源」）→【副作用】删除或移入 `pus/.trash/`（实现票二选一，界面文案按实际写法给）→ 列表 `ready`。
9. **带去问事**：触发 = 行「带去问事」→ 系统把该谱名放进待勾选集合（不写盘），跳 S6 → S6 勾选区出现该谱并 `ready`。
10. **边界跳转**：触发 = 列表底部说明里的链接 → 去 S8（挂载工作区 / 工作流）、去 S11（藏库）、去 S15（数据目录）→ 不写盘。

## 6. 关键状态

| 状态 | 什么时候 | 界面是什么样（可执行） |
|---|---|---|
| `empty` | `pus/` 下只有底座、一个可选谱都没有（或列表被筛空） | 空态图 + 「还没有可选谱：谱由你积累，**非必填、不阻塞使用**（唯一必填是底座八字）」+ 主按钮 `[＋ 创建第一个谱]`（打字 / 附件）+ 次按钮 `[先看底稿会怎么用它们（去 S13）]` + `[清空筛选]`（筛空变体时） |
| `loading` | 首次进入 / 打开详情 | 行级骨架（分组头先出、行后到）；详情骨架分三块，不整页转圈 |
| `error` | ①单谱 manifest 解析失败 ②`pus/` 读不到 | ①该行标 error + `[打开原始文件]` + `[忽略此谱]`，其余行照常 `ready`；②面板级错误 + `[重试]` + 一行只读路径展示（`~/.dsh/xuanshu/pus/`）+ `[去 S15 看整体拷走说明]` |
| `running` | 创建谱第 ③ 步 AI 转换中 / 重建 summary 中 | 进度条目（已解析 / 已分节 / 正在写 summary）+ `[中断]`；明写「中断不落盘」；此态下 `[确认落盘]` 不可点 |
| `stale`（陈旧） | 内容文件或 summary 的 mtime 晚于 manifest `updated_at`（人或外部编辑器改过） | 行内 Tag「汇总可能过期」+ `[重建 summary]`；详情页同样标记，不阻塞阅读 |
| 只读态 | 底座锁定行、元信息区 | 无编辑控件；锁定行只有 `[打开]` + 说明卡；元信息区纯文本 |
| 窄屏态 | <1100 | 见 §2.4：详情整屏下钻、行内动作收进行菜单；分组头规则文案保留 |
