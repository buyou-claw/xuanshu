## 1. 目的与入口

**目的**：让用户随时瞄一眼「我的设定」——从命盘卡点进去看八字要点，**看完就走，不可能误改**（C1）。

**从哪进**

- **唯一入口**：S1 自我总览 → 命盘卡 `[看详情]`；
- 命盘卡为 `empty` 时本抽屉打不开（S1 侧按钮置灰 + Tooltip「先填出生信息」）。

**去哪出**

| 控件 | 落到哪 |
|---|---|
| `[关闭]` / `Esc` / 点遮罩 | 回 S1（无副作用，不改变任何状态） |
| `[重新录制出生信息]`（**唯一写操作**） | 【人工确认闸门】二次确认弹窗 → S3 八字向导（**预填现值**），成功后回本屏重新读快照 |
| `[展开大运表 ->]` / `[展开]` 其它要点 | 就地展开（纯本地渲染） |

**相邻屏**：S1（父屏）；S3（唯一写路径）；S13 底稿面板（卡片内一句「改完源头后，底稿会在下次刷新时更新」+ 跳转，本屏**不自动写底稿**）。

## 3. 线框说明

> 线框内一律用 ASCII 符号（`-` 代替 `·`、`->` 代替箭头、`...` 代替省略号），以便 diff 与终端阅读；C1 要求的正式标记文案在 §9 逐字给出。

- ① **只读标记**：抽屉顶部固定一枚 `Tag`：**「只读 · 由出生信息与底座生成」**；全屏**没有任何输入框、开关、保存按钮**。
- ② **出生信息摘要行**：`YYYY-MM-DD HH:mm:ss 当地时间` + 地名 + 经纬度（度分串）+ 时区偏移。摘要行**不可就地编辑**——要改走 ⑧。
- ③ **四柱表**：四列（年 / 月 / 日 / 时）× 四行：**天干 / 地支 / 藏干 / 十神**。缺项按「—」显示并在本区块底部给一行说明（如「性别未知，大运按男排」），**不留空白格让人猜**。
- ④ **大运**：摘要行显示「起运 <n> 岁」+ `[展开大运表 ->]`（每步一列，宽屏内滚、窄屏横滑）。**只展示、不可改**；起运精度等旋钮由引擎缺省决定（不在本屏暴露）。
- ⑤ **其它要点**：纳音 / 神煞 / 空亡 / 命宫，默认收起、可展开。上游有「神煞显隐、只显示地支藏干十神」等开关——**v1 不提供**（见 §7），本屏给固定的一套要点。
- ⑥ **起盘口径只读行**：三行——`时间算法 = 真太阳时（经度 + 均时差）`、`性别 = 未知（按男排）`、`其余旋钮 = 引擎缺省（本盘未改）`。**只读展示，不可在本屏切换**；口径行同时也是「这盘到底怎么算出来的」的说明书。**注意：这里不出现晚子时 / 长生 / 命宫起法之类的档位**——它们由引擎缺省决定，玄枢 v1 不透传也不呈现（D4）。
- ⑦ **快照来源行**：`horosa <版本> / 出盘于 <日期>`。用途有两个：口径可追溯 + 版本漂移时能看出「这盘是旧底座算的」（见 §6 `stale`）。
- ⑧ **唯一写操作**：`[重新录制出生信息]`，点击**必过二次确认弹窗**（文案见 §5 第 4 步），确认后跳 S3。

## 5. 交互流程

1. **打开**：S1 命盘卡 `[看详情]` → `XsDestinyDrawer` 挂进 `shell.overlay` → 读 `~/.dsh/xuanshu/pus/_base/bazi.md` 快照 → 界面 `loading`（骨架）→ `ready`。**不重新出盘**（同一份出生信息两次出盘可能因上游版本差异产生不同结果，快照是唯一事实源）。**无副作用**。
2. **展开 / 收起**：大运表、其它要点就地展开（纯本地）；展开态只记在本次抽屉会话内，关掉即复位（避免下次进来看到一堆展开块）。**无副作用**。
3. **复制要点**：允许选择并复制文本（只读操作），界面不额外提供「导出 / 另存为」入口。
4. 【人工确认闸门】**重新录制**：点 ⑧ → 弹二次确认弹窗，正文写明：**「将重新录制出生信息并重新出盘。当前底座谱（`~/.dsh/xuanshu/pus/_base/bazi.md`）会被新结果原子替换；底稿会在下次刷新时随之更新，需要你手动点刷新。」** 按钮 = `[取消]` / `[去重新录制 ->]` → 确认后进 S3（**五步全部预填现值**）。
5. **S3 完成回来** → **【副作用】**S3 已重出盘并原子替换底座谱 → 本抽屉重读快照 → `loading → ready`；顶部出现一行「已于 <时间> 更新」提示条（3 秒后自动消失，不弹窗）。
6. **关闭**：`[关闭]` / `Esc` / 点遮罩 → 回 S1。**无副作用**；未保存任何东西（因为本来就没有可保存的东西——C1）。
7. **底稿联动（只提示、不代写）**：抽屉底部一行小字「改完源头后，底稿会在下次刷新时更新」+ `[去底稿]` → S13；**本屏不触发底稿刷新**（刷新的唯一按钮在 S1 底稿卡与 S13）。

## 6. 关键状态

| 状态 | 本屏表现 |
|---|---|
| `empty` | 底座未立时**本抽屉打不开**（S1 侧 `[看详情]` 置灰 + Tooltip「先填出生信息」）；若因并发被打开（如 S1 未刷新），抽屉内显示「还没有命盘：出生信息还没录」+ `[开始填写出生信息 ->]`（→ S3）+ `[关闭]` —— 空态可执行，不写「暂无数据」 |
| `loading` | 读快照期间的卡级骨架：四柱表 4×4 占位格 + 口径行 3 行占位；**不整屏转圈** |
| `error` | 分两种并各自可执行：**(a) 快照读不出来**（文件缺失 / 解析失败）→ 「命盘快照读不出来」+ `[重试]` + `[去重新录制出生信息]`（→ S3，二次确认）+ `[看数据目录 -> S15]`；**(b) 快照结构不符**（缺四柱字段）→ 显示已能读出的部分 + 一行「部分要点读不出来（<字段名>）」+ `[重试]`，**不整屏失败** |
| 只读态（本屏常态） | 全屏零输入控件；唯一按钮 `[重新录制出生信息]`（写操作，带二次确认）；`[关闭]`、`[展开]` 均非写操作 |
| 禁用态 | `[展开大运表 ->]` 在缺性别以外的情况照常可用；若引擎未回大运（如极早年月超出支持范围）→ 该按钮置灰 + 说明「此盘未排大运（<原因>）」+ `[改出生信息]`，**不给点了没反应的按钮** |
| `stale`（陈旧） | 快照的底座版本 ≠ 当前钉版（ADR-0004：horosa-skill v0.40.1）时，抽屉顶部常驻一条提示：「此盘由 horosa `<旧版本>` 生成，当前底座是 `<版本>`」+ `[重新出盘 ->]`（→ S3，二次确认）；**不静默当作最新** |
| 窄屏态 | 抽屉铺满 + 单列（§2.2）；大运表横向滑动；底部 `[重新录制出生信息]` 吸底 |
