## 1. 目的与入口

**它解决什么**：把此前「留到 UI 阶段再定」的三件事收口——
1. **管理入口放哪**（原：设置菜单 vs 左上角入口条）→ 按 **D1**：走 `sidebar.panellist`；设置菜单只放系统项。**D7 修正**：rc.2 的 `sidebar.panellist` 只读 `{id, order, label}`、**没有分组字段**，所以 D1 的「分区」只能落成「多行 + order 分段 + label 措辞」，**不承诺分组容器与分隔线**。
2. **骨架长什么样**：落位后的侧栏行 + main 面板 + 浮层/抽屉一次画清，标出哪些是玄枢自有 key、哪些是 DSH 原样。
3. **数据在哪、怎么带走**（C11）：`~/.dsh/xuanshu/` 与 `~/.dsh/sessions/` 的只读路径展示 + 「整体拷走」说明（承接 S1 页眉只展示的那一行路径，这里给完整版）。

**从哪进**：本屏不是「一屏页面」而是**骨架 + 一个设置内页**：侧栏行从任何界面都可见；设置 → `数据与拷走`（本屏 E 区）。

**去哪出**：
- 侧栏六行 → 六个 main 面板（S1 / S6-S7 / S5 / S11 / S13 / S12）。
- 定时任务 → **DSH 原样的 `schedules` 面板**（§6.5：玄枢不另造）。
- 设置 → 本屏 E（数据与拷走）+ DSH 原样的模型 / 审批 / 插件（MCP）/ 技能中心。

**相邻屏**：全部自有屏（本屏是它们的落位依据）；与 DSH 原样界面的接缝在 §8 逐个标清。

## 4. 组件树

> **写法规矩（F4/D9）**：本节一律写「**照 X 形状自研**」——不 `require` `@deepseek-ai/dsh-client-ui-primitives` 或任何 Harness Client 包；类名走 `--xs-` 前缀，样式只保留 `--dsw-alias-*` / `--xs-*` token 引用。`shared/DSH槽位映射.md` §5 是**形状参照**，不是依赖清单。

- `XsPanellistRows`（自研，**只注册行、不重画侧栏**）— 六个 `sidebar.panellist` 行（`overview` order 20 / `consult` 30 / `pus` 40 / `cang` 50 / `digao` 60 / `workflow` 70），每个是图标 + label；**无分组容器**。
- `XsBrandMark` / `XsBrandName`（自研）— `sidebar.brand.mark` / `sidebar.brand.name`（只换标与名，不动 DSH 的其余侧栏控件）。
- `XsPanelHeader`（自研）— 玄枢六个 main 面板共用的面板头（面板名 + 该面板主操作位）；非 conversation 面板**不接会话座位**，只消费 root 座位（`usePanelInfo` / `useSessions` / `useSessionsStatus` / `useWorkspaces`）。
- `XsDataPortabilitySection`（自研）— `settings.section`：`id: xuanshu.data`、`order: 40`。
  - `XsDataPathTree`（自研）— 目录树只读展示（两级展开）。
  - `XsCopyPathAction` / `XsOpenDirAction`（自研）— 复制路径（形状照 DSH 行内动作）/ 在文件管理器中打开（能力复用 DSH open-in-app 的目录路由）。
  - `XsTakeAwayNote`（自研）— 「整体拷走」说明 + 三个「不包含」。
- `XsDrawerShell`（自研）— 通用抽屉外壳（照 DSH `Modal` 的形状与行为：焦点管理、遮罩、Escape 关闭），落 `shell.overlay` 的独立条目，自行恢复 pointer-events；供 **S2 / S8 / S11 / S14** 复用。
- `XsDialogShell`（自研）— 居中对话框外壳（同上形状），供 **S10**（沉淀确认，人工闸门）复用。
- **不占浮层**（刻意列出，便于评审反查）：**S5 的创建谱 = `pus` 面板内的自绘视图切换（面板内子页）** —— 不新增 main key、不进 `shell.overlay`、不用居中对话框。理由：创建谱是 `pus` 面板的主流程，需要保持谱列表上下文；且 DSH 无抽屉原语、浮层位留给 S2 / S8 / S11 / S14 的抽屉与 S10 的确认对话框。
- 接管：**不注册** `root` / `sidebar` / `sidebar.workspaces` / `sidebar.settings` / `rightbar` / `main.conversation` / `conversation.*` 的任何槽（那些属于 DSH 原样界面或别的屏）。
- **归属检查**：玄枢只往四个**加性/键控**槽登记：`sidebar.panellist`（list）、`main`（keyed，每 key 一次独立 `register`）、`settings.section`（list）、`shell.overlay`（list）；外加两个品牌 single 槽（`sidebar.brand.mark` / `.name`，无 occupation、replaceRisk none）。

## 5. 交互流程

1. 装配启动（触发：`dsh web` 加载 xuanshu profile）→ **【副作用】** 玄枢注册六行 panellist、六个 main key、一个 settings.section、品牌标 → 界面：侧栏出现玄枢六行（与 DSH 的插件 / 自动化任务行同列），默认面板 = `overview`。
2. 人点某个侧栏行（触发：`selectPanel(id)`）→ 界面：main 切到该 key；行进入 `active`；面板头显示面板名。
3. 人点 DSH 的「工作区 / 项目 / 会话」或「自动化任务」（触发：DSH 原样交互）→ 界面：进入 DSH 原样区域（玄枢不介入，也不遮蔽）。
4. 人在门厅（`consult`）点「进入会话」（触发：按钮，**D5/D6**）→ **【副作用】** `ctx.layout.selectPanel(null)` → 界面：main 切回 DSH 原生 `conversation` 面板并显示该会话；此后 `conversation.*` 子槽（勾选谱条 / 挂载入口 / 合参 / 沉淀 / **审批卡**）才渲染。
5. 人从任何界面打开某个详情抽屉（触发：各屏自己的按钮）→ **【副作用】** 在 `shell.overlay` 注册/显示自研抽屉条目 → 界面：抽屉浮在列之上；Escape / 遮罩关闭；焦点被限制在抽屉内。
6. 人进设置 → `数据与拷走`（触发：设置导航）→ **【副作用】** 宿主 fs 服务读两个目录的**结构**（只读，不读文件内容）→ 界面：E 区；状态 `ready`。
7. 人点 `[在文件管理器中打开]`（触发：按钮）→ **【副作用】** 系统文件管理器打开 `~/.dsh/xuanshu/` → 界面：焦点离开玄枢。
8. 人点 `[复制路径]`（触发：按钮）→ **【副作用】** 写系统剪贴板（只写路径文本）→ 界面：按钮短暂回显「已复制」。
9. 人按 E ③ 自己复制目录（触发：玄枢之外的文件操作）→ 界面：本页**不做**搬运动作；「整体拷走」是说明 + 指路。

## 9. 硬约束在 UI 上的呈现

本屏矩阵（README §5）：**C11 ●**、**C3 ○**；其余不涉及。

**C11 一切数据本地、可整体拷走**（本屏是主场）
- `设置 ▸ 数据与拷走` 常驻两块**只读路径展示**：`~/.dsh/xuanshu/`（`pus/` / `digao.md` / `cang/registry.jsonl` / `sediment/`、`exports/`）与 `~/.dsh/sessions/`；路径旁只有 `[复制路径]` 与 `[在文件管理器中打开]`，**没有编辑 / 删除 / 清空**。
- 「整体拷走」写成可执行说明（复制这两个目录即带走全部玄枢数据）+ 三个**不包含**：DSH 的模型凭据与 API Key、horosa 的记忆与落库（上游自管）、藏指向的本机文件（拷走注册表 ≠ 拷走那些文件）。
- **承接 S1 页眉**：S1 四卡区只展示 `~/.dsh/xuanshu/` 一行（点它跳本屏），完整目录树、拷走说明与三个不包含都在本屏给全 —— 两屏逐字一致，不各说一套。
- token 承载：`text-code`（路径）+ `surface-panel` + `--xs-size-panel-content-max`；「整体拷走」说明处用 `--xs-constraint-human-gate-fg/-bg`（它是「你亲手复制」这件事的说明，不是提示装饰）。

**C3 藏不可见 AI（○ 涉及处）**
- 侧栏第 50 行「藏」在骨架图上标注「永不上 AI」；落位表（§8）备注列同样写明。
- 骨架层面**不存在**把藏拖进 AI 的入口：`cang` 面板不注册会话槽（`conversation.*` 一个都不占）、不进挂载抽屉（挂载只列工作区 / 工作流，S8）、侧栏行里没有「让 AI 看藏」。
- 设置里与藏相关的只有「数据与拷走」里的注册表路径一行，写明「只存指针 + 签 + 跳转，不存内容」。
- token：`--xs-constraint-noai-fg/-bg` **只用于藏库顶部那句常驻声明**（S11），本屏只用于侧栏行的「永不上 AI」小标；**不得**用来给任何 AI 动作按钮上色（那等于承认按钮存在）。
