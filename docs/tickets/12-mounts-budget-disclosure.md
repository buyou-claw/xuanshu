# 12: 临时挂载（工作区/工作流，预算裁剪披露）

**What to build:** 问事会话里可临时挂载某个具体工作区或工作流，针对它深入提问。挂载内容注入前按「挂载预算」分层裁剪并披露（预览 + 裁减说明 + 状态栏字数，照星阙挂载账本模式）。挂载清单走会话 meta 的 `mounts`，与勾选谱（`pus`）并列。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 问事里可临时挂载某个工作区/工作流（路径或实体 id）
- [ ] 注入前按预算分层裁剪并披露（预览 + 裁减说明 + 字数状态）
- [ ] 挂载走会话 meta `mounts`，与 `pus` 并列、互不混淆；工作区/工作流不是谱、不出现在谱列表
