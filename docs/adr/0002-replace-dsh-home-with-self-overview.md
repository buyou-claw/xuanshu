# 用「自我总览」替换 DSH 首页，其余子系统界面完全复用 DSH

DSH 的首屏是工作区 / 会话列表，而玄枢的定位是「以你为中枢」。**决定：玄枢的首页是自我总览，它替换掉 DSH 原来的首页；而子系统界面（工作区 / 项目 / 会话列表 / 设置）完全复用 DSH，不改动。**

**Considered Options**：把自我总览做成分散在侧边栏的普通入口（改动最小，但首屏不再是「我」，中枢感消失）——被否，因为「首页即我」是产品灵魂的体现，不是可选项。

**Consequences**：这条越过了「纯加插件」的边界，进入「改装配」——需要替换 DSH 布局中某一槽位的占据者，这一处改动成为玄枢自有代码的维护点，也是将来跟随 DSH 版本时唯一的合并点。允许这样做的底气来自 ADR-0004（锁定固定版本，不实时跟随上游）。
