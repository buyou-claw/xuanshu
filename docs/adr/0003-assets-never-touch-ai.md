# 资产永远不上 AI

「资产」指**你自己的、本地既有的文件**（书籍、文章 / 视频 / 网页资料、收藏夹、密码…）。**决定：玄枢对资产只做三件事——登记指针、打标签、生成跳转入口；不读、不索引、不分析、不进任何上下文，也不对文件本身做任何操作。** 同时明确 **模块不属于资产**（模块是要被 AI 理解消化的信息型系统）。

**Considered Options**：允许 AI 索引资产以便检索与引用（功能更强）——被否。理由：资产的价值在于「它只是客观存在的东西」；一旦它可以被检索进上下文，密码一类东西就与书籍同处一条通道，任何一次误勾选都是事故。这条分界线是安全不变式，不是偏好。

**Consequences**：玄枢**明确放弃**「智能检索你所有资料」这项能力；资产的可用性来自标签与跳转，而不是搜索与理解。将来若要做，只能另开一条与 AI 隔离的通道，不能松动本 ADR。

> 注：本文写作时用的词是「资产」，**该词随后改名为「藏」**（其管理子系统称「藏库」）；决定本身未变。
