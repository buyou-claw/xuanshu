# 藏库登记与找回

用户把一份本地文件登记为藏，记录指针和签，重启后还能搜索并找回。界面依据为仓库 `docs/design/ui-v1/screens/S11-藏库.md`。

## Sub-features

- `cang-entry` 从应用根入口找到藏库和登记抽屉。
- `cang-correct-path` 错误路径有提示、禁用登记，改正后可提交。
- `cang-retrieve` 按签搜索，服务重启后可找回相同登记。

## How to get to it (user POV)

自我总览提示管理入口在侧栏。侧栏「藏」进入藏库，空态点「登记第一个藏」，非空态点「登记藏」。观察抽屉提供的输入方式。

## Driving it with scripts/experience

前置为新 home、空注册表、合成木工笔记。可在本轮 `runDir` 创建 `木工练习笔记.txt`，另用同目录未创建的 `木工练习笔记-不存在.txt`。两者都使用绝对路径，保留合成文件供复跑。

- **观察入口。** 发 `{type:"observe", reason:"找本地资料登记入口"}`。可见模型提示时可点击按钮「稍后配置」。根据自我总览和侧栏选择「藏」，用截图和可访问树确认空态。
- **检验异常。** 从实际空态打开「登记第一个藏」。`registry` 记录初态。先填「名称」等其余必填项，再对 `{role:"textbox", name:"本地文件 / 文件夹路径"}` 使用 `fill`，填入不存在的路径。用 `observe` 或 `check` 捕获失效文案和「登记」禁用，再确认注册表零行。
- **恢复并登记。** 保持名称和其他必填项相同，只把路径改成合成文件的真实路径。建议名称「木工练习笔记」，并在「签（用逗号分隔）」填只出现在签里的「手艺」。确认「登记」启用，普通点击。观察完整卡片标题，当前常见标题为「木工练习笔记 已登记」。用 `registry` 核对同一条记录的 ID、名称、签、路径与哈希。
- **重启并找回。** 发 `restart` 重启服务。查看新启动代，实际出现首跑提示时正常关闭。重新由侧栏进入「藏」，在文本框「搜藏名 / 签」先输入一个无匹配词，再输入只出现在签里的「手艺」。分别确认卡片隐藏和重新可见，`registry` 核对同一 ID 与哈希。截图保留错误、修正、登记和重启后找回。
- **缩减。** 取本轮真实轨迹，选择预期拒绝或实际看到的异常，按[重放配置](../references/replay.md) 重放。记下原始路径、删掉的动作和重复验证结果。

## Gotchas

- `check` 的名称和正文按精确匹配处理。先从快照读实际标题，保留「已登记」等状态文字。遮罩拦截与定位失败先查截图。
- 重启后的 200 和磁盘留存不能单独证明用户找回。页面空白时按 Doctor 核对控制台和端口，保存失败，再在同一 home 有界重试。若始终进不去，界面回看记为受阻，另报磁盘结果。
- 手动粘贴路径只覆盖该登记方式。系统文件选择器、打开默认程序、键盘全路径需要各自的操作证据。
