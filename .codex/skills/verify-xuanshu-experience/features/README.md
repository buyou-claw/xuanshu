# 玄枢功能地图

先按 [技能入口](../SKILL.md) 启动并核对独立 Edge 实例。从用户目标出发选一页。括号内的前置缺失时，把对应场景记为受阻并保存证据。记录走过的入口与界面状态。

| 用户目标 | 功能 |
| --- | --- |
| 登记本地笔记，下次仍找得到 | [藏库](cang.md)（无模型） |
| 录入出生信息并看命盘 | [自我总览和命盘](overview.md)（正常出盘需要实际 horosa） |
| 问一件事，再回看同一场问事 | [问事与历史](consult.md)（真实会话需要测试模型） |
| 把一份资料建成可管理的谱 | [谱管理](pu.md)（AI 转换需要测试模型） |

选择正常、异常和恢复路径时以实际任务范围为准。藏库是本轮冷启动实跑路径；其他三页是由仓库入口和设计稿核对的后续验证地图。
