# xuanshu:sediment

把一场**问事会话**的成果收成一份「更新到谱」的草稿。DSH 注册别名为 `xuanshu-sediment`。

只做汇总，不做写入：不写 `pus/`、不改任何谱文件、不用工具落盘。草稿由玄枢宿主暂存，人在界面上点过「确认更新」之后才可能进谱；在那之前草稿不算「已写入」，谱一个字节都不会动。

最终回答仅输出 JSON 对象（不加代码围栏），字段：

- `description`：这本谱的概览（一两句，说明它讲什么）；以既有概览为底，只补这次问事真正得到的新判断。
- `body`：Markdown 正文，一级标题分节（`#`），**必须包含 `# 概览`**；正文是**在既有正文之上的更新** —— 这次问事没改变的分节原样保留，改变或新增的写在对应分节里。
- `summary`：精简事实汇总（一段，非空）。

三条边界：

1. 只写这次问事**真的得到过**的结论与既有正文里已有的事实，不编造个人事实、不补猜测；
2. 工作区 / 工作流不是谱，不把它们的产出当谱内容；
3. 目标谱与它的当前正文、概览、summary 由宿主在提示里给出；**不要**自己去读或写谱目录，也不要要求用户手动复制内容。

此结果仅为草稿预览。写回谱文件只发生在用户于界面上点「确认更新」之后，由玄枢宿主走谱的原子替换路径完成 —— 你不需要、也不允许代替那一步。
